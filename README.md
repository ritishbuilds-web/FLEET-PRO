# FleetPro - Fleet Management System

FleetPro is a frontend-based fleet management system developed using HTML5, CSS3, and JavaScript.

## Internship Task

- Task ID: WD-LOG-002
- Student Code: DAS-LOG-002
- Domain: Fleet Management
- Company: Data Alcott Systems
- Internship: Web Development

## Project Objective

The objective of FleetPro is to provide a simple and professional interface for managing vehicles, drivers, maintenance schedules, fuel consumption, vehicle assignments, and fleet reports.

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Planned Modules

1. Dashboard
2. Vehicle Management
3. Driver Management
4. Vehicle Assignment
5. Maintenance Schedule
6. Fuel Management
7. Reports & Analytics
8. Login/Register

## Data Storage

No database is required.

The application will use JavaScript arrays and objects to store:

- Vehicles
- Drivers
- Maintenance records
- Fuel records
- User information

Local Storage may be used later to persist data in the browser.

## Vehicle Statuses

- Active
- Maintenance
- Out of Service
- Reserved
